## 1. Правило (семантика — соблюдать точно)
- `slope = (EMA3(close_1h)[i] / EMA3(close_1h)[i−1] − 1) * 100`, по **закрытым** 1H-барам; незакрытый 1H-бар не использовать (никакого look-ahead).
- Момент оценки = **момент постановки лимитки/сигнала** (тот же якорь, от которого считается окно ожидания входа). НЕ `floor(htf_time,'1h')` — это начало 8H-окна, до 7 часов назад.
- LONG разрешён только при `slope > +0.02%`; SHORT — только при `slope < −0.02%`.
- `|slope| < 0.02%` — мёртвая зона: **разрешены обе стороны** (боковик).
- Нет данных / исключение → **fail-open** (разрешаем) + `logger.warning`.
- Вкл/выкл и порог — из CONFIG, дефолт: включено, 0.02%.
- Запрет = сигнал пропускается целиком (SKIP). Не «ждать», не «отложить», не «уменьшить размер». **Висящую лимитку и открытую позицию НЕ трогаем** — гейт только на входе.
